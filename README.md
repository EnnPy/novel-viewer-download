# 소설뷰어 다운로드

개인용 소설 뷰어 앱의 **테스트 빌드**입니다. 앱에는 책(소설) 파일이 들어 있지 않으며, 본인이 가진 파일을 직접 불러와 사용합니다.

최신 버전: [Releases](https://github.com/EnnPy/novel-viewer-download/releases/latest)

웹에서 바로 쓰기: https://ennpy.github.io/novel-viewer-download/

## Android
1. Releases에서 `novel-viewer-android-*.apk`를 내려받습니다.
2. 설치 시 "출처를 알 수 없는 앱" 설치를 허용합니다.
3. 이후 버전은 같은 서명으로 배포되므로 기존 앱 위에 그대로 덮어 설치(업데이트)할 수 있습니다.

## iPhone
1. Releases에서 `novel-viewer-ios-*.ipa`를 내려받습니다.
2. PC에서 [Sideloadly](https://sideloadly.io/)를 설치하고, 무료 Apple ID로 IPA를 iPhone에 설치합니다.
3. 무료 Apple ID는 7일마다 만료되므로 7일 안에 다시 설치해야 합니다.
4. 설정 > 일반 > VPN 및 기기 관리에서 해당 개발자 프로필을 "신뢰"합니다.
5. iOS 16 이상은 설정 > 개인정보 보호 및 보안 > 개발자 모드를 켜야 합니다.

## 참고
- 테스트 빌드이므로 오류가 있을 수 있습니다.
- 앱에 책은 포함되어 있지 않습니다.
